# CLAUDE.md — oci-mysql

## What This Project Does

Deploys a private MySQL HeatWave DB System on OCI plus an Ubuntu phpMyAdmin VM
in a public subnet. The VM connects to MySQL over TLS using the DB system's
private IP and loads the Sakila sample database on first boot.

Single Terraform phase in `01-mysql/`. No modules, no workspaces.

## Commands

```bash
./apply.sh              # check env, terraform init + apply, then validate
./destroy.sh            # teardown all resources
./validate.sh           # poll phpMyAdmin URL until reachable, print summary
./get_password.sh       # print MySQL + VM credentials from tfstate
./check_env.sh          # validate oci/terraform/jq in PATH + OCI CLI connectivity
```

## Architecture

```
VCN: 10.0.0.0/23
  ├── mysql-subnet (10.0.0.0/25) — private, NAT gateway
  │     └── oci_mysql_mysql_db_system  (MySQL.2, port 3306)
  │
  └── vm-subnet (10.0.1.0/25) — public, Internet Gateway
        └── oci_core_instance  (Ubuntu 24.04, phpMyAdmin, port 80)
                                   └── connects to MySQL private IP over TLS
```

- **Region:** us-ashburn-1
- **MySQL shape:** `MySQL.2` (2 OCPUs, 32 GB RAM, 50 GB storage)
- **VM shape:** `VM.Standard.E4.Flex` (1 OCPU, 4 GB RAM)
- **MySQL provisioning:** typically 10–20 minutes

## Auth Pattern

- `~/.oci/config` DEFAULT profile — no credentials in code
- `OCI_COMPARTMENT_ID` env var → `TF_VAR_compartment_ocid` in apply/destroy
- Falls back to tenancy OCID from `~/.oci/config` if env var is unset
- SSH key generated by Terraform (ECDSA P-256), written to `01-mysql/keys/Private_Key`

## Secrets / Passwords

OCI Vault is not used. Passwords are `random_password` resources exposed as
sensitive Terraform outputs in `tfstate`. Retrieve with `./get_password.sh`.

- `mysql_password` — MySQL admin (`sysadmin`) password
- `vm_password` — Ubuntu VM user (`ubuntu`) password; injected via cloud-init `chpasswd`

## Security Lists

OCI security lists attach at the subnet level — all resources in a subnet
share the same rules.

| Subnet | Security List | Rules |
|--------|--------------|-------|
| mysql-subnet | `mysql-sl` | Ingress TCP 3306 from `10.0.1.0/25` only |
| vm-subnet | `mysql-vm-sl` | Ingress TCP 80 and TCP 22 from `0.0.0.0/0` |

Both lists allow unrestricted egress.

## Cloud-Init Quirks (baked into phpmyadmin.sh.template)

1. **Network timing:** OCI fires cloud-init before internet routing is stable.
   Script loops on `curl -4 http://archive.ubuntu.com/` until reachable.
2. **apt lock race:** OCI boots cloud-init so fast that `apt-daily` grabs the
   apt lock first. Fix: retry loop on `apt-get update` with `pkill -9 -f apt`.
3. **IPv6 / IGW:** Force IPv4 for apt via `/etc/apt/apt.conf.d/99force-ipv4`.
4. **iptables catch-all REJECT:** OCI Ubuntu images have a catch-all iptables
   REJECT rule at INPUT position 5. Port 80 is not pre-allowed. Fix:
   `iptables -I INPUT 5 -p tcp --dport 80 -j ACCEPT`.

## SSH to phpMyAdmin VM

```bash
ssh -i 01-mysql/keys/Private_Key -o StrictHostKeyChecking=no ubuntu@<phpmyadmin_public_ip>
```

Public IP is in Terraform outputs and printed by `./get_password.sh`.

## MySQL Connection (from within VM)

```bash
mysql -h <mysql_ip> -u sysadmin -p --ssl-mode=REQUIRED
```
